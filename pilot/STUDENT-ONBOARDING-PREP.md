# Student Onboarding — Pre-Live Preparation

This package is prepared for the controlled HED3505 pilot but must not be used to invite real students until the roster authorization gate passes.

## Student flow

1. Create or confirm a GitHub account.
2. Accept access to the private pilot repository.
3. Read the privacy notice.
4. Read the AI-use policy.
5. Complete a sample submission before any assessed task.
6. Confirm automated structural validation succeeds.
7. Confirm understanding of evidence and reflection requirements.

## Readiness confirmation

A student is READY only when repository access, sample submission, validation, and privacy/AI-policy acknowledgment are all verified.

Official grades remain outside GitHub during the initial pilot.
