# Roster Evidence Intake Checklist

Phase: RU-HEPE-CLASSROOM-03B.1

Status: AUTHORIZED / WAITING FOR AUTHORITATIVE ROSTER EVIDENCE

Use this checklist before any real-student identity binding.

## Accepted source classes
- AUTHORITATIVE — official university/course registration roster
- VERIFIED COPY — instructor-confirmed copy matched to the official roster
- UNVERIFIED — do not bind
- REJECTED — do not use

## Required intake checks
- [ ] Source identified
- [ ] Source classified as AUTHORITATIVE or VERIFIED COPY
- [ ] Course is HED3505
- [ ] Current teaching period confirmed
- [ ] Pilot size limited to 3–5 students
- [ ] Selection method documented without sensitive criteria
- [ ] GitHub username supplied by or verified with each participant
- [ ] No guessed GitHub usernames
- [ ] No roster/student ID committed to public repositories
- [ ] No official grades stored in GitHub

## Release condition
Only after all checks pass may selected records move to `IDENTITY_MATCH_PENDING` and then `VERIFIED`.

No repository provisioning or invitation is authorized by this checklist alone.
