# HED3505 Pilot — Sample Submission Acceptance

## Purpose
Validate the learning workflow before a participant receives a real course assignment through the pilot.

## Required sample-flow checks
1. Participant can access the private repository.
2. Participant can locate README and assignment instructions.
3. Participant can add a sample artifact without personal or sensitive data.
4. Participant can complete a short reflection.
5. Submission or pull-request workflow works as configured.
6. Automated structural validation runs.
7. Instructor can provide feedback.
8. Participant can revise the sample submission.

## Participant-level result
Use one of:
- PASS
- PASS WITH MINOR WARNING
- FAIL — CORRECTION REQUIRED

A participant cannot proceed to a live assignment while status is FAIL.

## Important boundary
This sample workflow does not generate an official grade and does not confirm official enrollment.
