# Instructor Guide

## HED3505 GitHub Learning Hub

Use this repository as the canonical controlled course-material source for the HED3505 pilot.

The operating flow is:

**Teaching → Student Activity → Evidence Capture → Feedback → Portfolio**

## Instructor responsibilities

- release activities from verified course materials
- define explicit evidence requirements
- review submissions using approved rubrics
- provide feedback through the designated repository or portfolio workflow
- keep official grades and sensitive records outside public GitHub repositories
- verify authoritative evidence before publishing CLO/PLO mappings, assessment weights, schedules, or roster claims

Automated checks may support structural validation only. Final academic judgment remains a human/instructor responsibility.

## GitHub Classroom migration

Do not provision or design new workflows that depend on GitHub Classroom.

Use:
- `course-hed3505` for canonical course materials
- `assignment-template` for reusable assignment structure
- `student-portfolio-template` for evidence and reflection
- `course-hub` for learning navigation
- private student repositories where student-specific work is required
