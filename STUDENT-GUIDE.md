# Student Guide

## HED3505 GitHub Learning Hub

Use the course learning materials in sequence. For each assigned task:

1. Open the activity from the HED3505 course hub.
2. Complete the required learning task.
3. Save only the evidence requested by the activity.
4. Add a short reflection when required.
5. Submit through the designated repository, pull-request, or portfolio workflow.

## Evidence workflow

**Activity → Evidence → Reflection → Feedback → Portfolio**

Automated checks may validate file structure or required fields only. They do not assign academic grades.

## Privacy

Do not place student ID numbers, private contact information, health information, official grades, or confidential school information in a public repository.

Student work should remain private by default unless the instructor explicitly authorizes another arrangement.

## GitHub Classroom

GitHub Classroom is not required for this course. Course participation and submission are handled through the HED3505 GitHub Learning Hub repositories and approved submission workflows.
