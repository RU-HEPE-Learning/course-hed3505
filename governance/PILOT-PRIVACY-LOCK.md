# Pilot Privacy Lock

Phase: RU-HEPE-CLASSROOM-03A

## Locked defaults

- Course materials: PUBLIC where academically appropriate.
- Student assignment repositories: PRIVATE.
- Student portfolio repositories: PRIVATE.
- Roster mapping: NOT STORED in public repositories.
- Official grades: NOT STORED in GitHub during initial pilot.
- Minimum necessary data only.

## Public-data prohibition

Do not publish student ID numbers, phone numbers, addresses, national identifiers, health information, official grades, or other sensitive personal data.

## Release gate

Any change from PRIVATE to PUBLIC for student work requires an explicit later human decision and appropriate consent/privacy review.
