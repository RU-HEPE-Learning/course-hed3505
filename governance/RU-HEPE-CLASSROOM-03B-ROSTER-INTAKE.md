# RU-HEPE-CLASSROOM-03B — Authoritative Roster Intake

Status: PREPARED / NO REAL STUDENT DATA

## Purpose
Prepare the controlled intake and verification process for a 3–5 student HED3505 pilot without placing real roster data in this public repository.

## Accepted source classes
- AUTHORITATIVE — official course registration roster or university registration-system export.
- VERIFIED COPY — instructor-verified copy traceable to the official roster.
- UNVERIFIED — may not be used for binding.
- REJECTED — may not be used for binding.

## Minimum binding fields
Only the minimum fields should be used in the controlled record held outside public repositories:
- Internal Pilot ID
- GitHub username
- Enrollment verification state
- Identity binding state
- Access state

Do not place student ID numbers, private email addresses, phone numbers, grades, addresses, health information, or other unnecessary personal data in public repositories.

## Binding states
PENDING → IDENTITY_MATCH_PENDING → VERIFIED → READY_FOR_ACCESS → ACTIVE

Withdrawal states: WITHDRAWN / ACCESS_REVOKED.

## Release rule
No real-student repository may be provisioned and no invitation may be sent until the roster source is classified AUTHORITATIVE or VERIFIED COPY and the selected GitHub usernames are individually verified.
