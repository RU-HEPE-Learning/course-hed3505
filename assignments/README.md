# HED3505 Assignments

Assignments in this course should be derived from verified teaching plans and the master case **โรงเรียนอรุณพัฒนา**.

Each assignment should include:
1. task purpose and instructions,
2. required evidence/artifacts,
3. submission format,
4. rubric or assessment criteria,
5. reflection prompt where appropriate.

Use `RU-HEPE-Learning/assignment-template` as the reusable baseline.
