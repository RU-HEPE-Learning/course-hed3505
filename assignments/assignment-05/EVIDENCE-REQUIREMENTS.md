# Evidence Requirements — Assignment 05

Required evidence:

1. evaluation question;
2. priority issue;
3. indicator;
4. data source;
5. instrument / method;
6. evidence-quality requirement;
7. analysis / interpretation approach;
8. decision rule;
9. limitation / uncertainty;
10. recommended next action;
11. traceability to WS1–WS4;
12. portfolio evidence link or location.

Every element must trace back to approved evidence or an explicitly identified evidence need.
