# Evidence Requirements — Assignment 03

Required evidence:

1. selected item / observation from WS2;
2. objective or indicator the item is intended to measure;
3. content-validity reasoning;
4. IOC evidence from an explicitly labeled instructional/simulated expert-rating dataset;
5. reliability evidence where appropriate from an explicitly labeled instructional/simulated dataset;
6. interpretation of validity and reliability evidence;
7. decision: **RETAIN / REVIEW / REVISE / REMOVE**;
8. rationale for the decision;
9. revision needed, if any;
10. evidence that is still missing.

Do not present simulated IOC/reliability data as actual data from โรงเรียนอรุณพัฒนา.
