# HED3505 Navigation Map

## Student entry

```
Course Hub
   ↓
HED3505 Course Workspace
   ↓
Student Guide
   ↓
Current Week
   ↓
Matching Assignment
   ↓
Evidence Requirements
   ↓
Private Submission / Portfolio
   ↓
Instructor Feedback
   ↓
Final Portfolio Evidence
```

## Primary navigation

| Need | Go to |
|---|---|
| Start the course | `README.md` |
| Understand the workflow | `STUDENT-GUIDE.md` |
| See the full student path | `STUDENT-JOURNEY.md` |
| Study weekly material | `weeks/` |
| Complete a task | `assignments/` |
| Check assessment criteria | `rubrics/` |
| Find approved course evidence | `evidence/` |
| Prepare portfolio evidence | `portfolio/` |
| Understand submission routing | `SUBMISSION-WORKFLOW.md` |

## Week-to-assignment routing

- Week 01 → `assignments/assignment-01/`
- Week 02 → `assignments/assignment-02/`
- Week 03 → `assignments/assignment-03/`
- Week 04 → `assignments/assignment-04/`
- Week 05 → `assignments/assignment-05/`

## Design constraint

Navigation should remain usable from a smartphone browser and should not require GitHub Classroom, a command line, or a mandatory backend.
