# Activity

## Module 5 — การสร้างแผนประเมินผลแบบบูรณาการ

### Design pattern
**Prompt → Tap → Reveal → Discuss → Decide → Save**

### Learning flow
1. **Check-in** — ทบทวน WS1–WS4 และเลือกหลักฐานสำคัญที่สุด
2. **Pre-test** — ตรวจ Question ↔ Indicator ↔ Instrument ↔ Evidence
3. **Live Poll** — เลือกจุดที่อ่อนที่สุดของแผนประเมินตัวอย่าง
4. **Class Result** — อภิปรายว่า “แผนที่ครบ” ต่างจาก “แผนที่สอดคล้อง” อย่างไร
5. **Alignment Card** — ตรวจ Evaluation Question → Indicator → Instrument → Data Source
6. **Evidence Quality Gate** — ตรวจ validity / reliability / missingness / contradiction
7. **Decision Rule Challenge** — กำหนดว่าจะใช้หลักฐานอย่างไรโดยไม่ overclaim
8. **Decision Point** — เลือกลำดับความสำคัญของการประเมินและเหตุผล
9. **WS5 Integrated Evaluation Plan** — รวม WS1–WS4 เป็นแผนฉบับเดียว
10. **Exit Ticket** — ระบุ “จุดอ่อนหนึ่งจุด” ของแผนตนเองและการแก้ไขรอบถัดไป

### Student product
**WS5 — Integrated Evaluation Plan**

### Evidence rule
ทุกองค์ประกอบของแผนต้อง trace กลับไปยังคำถาม ตัวชี้วัด เครื่องมือ และหลักฐานที่มีอยู่ ห้ามเติมข้อมูลโรงเรียนที่ไม่ปรากฏใน baseline
