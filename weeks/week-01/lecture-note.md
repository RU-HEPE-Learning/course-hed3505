# Lecture Note

## Core concepts
- Measurement: obtaining data using defined rules or instruments.
- Assessment: interpreting collected information to understand status or learning.
- Evaluation: judging value, merit, effectiveness, or improvement needs against criteria.
- Output: immediate product or delivery of an activity.
- Outcome: change observed after or because of the program, with attribution interpreted cautiously.

Use the โรงเรียนอรุณพัฒนา baseline to practice separating description from judgment.
