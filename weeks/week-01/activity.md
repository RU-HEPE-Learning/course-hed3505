# Activity

## Module 1 — จากปัญหาสู่สิ่งที่ต้องประเมิน?

### Design pattern
Mobile-first Active Learning using the repeating micro-interaction cycle:

**Prompt → Tap → Reveal → Discuss → Decide → Save**

### Learning flow
1. **Check-in** — นักศึกษาระบุความเข้าใจเบื้องต้นว่า “ข้อมูล” ต่างจาก “ตัวชี้วัด” อย่างไร
2. **Pre-test** — คำถามสั้นเพื่อดึงความรู้เดิมเรื่อง Measurement / Assessment / Evaluation
3. **Live Poll** — เลือกว่าข้อมูลใด “น่าจะ” ใช้ตัดสินโปรแกรมได้
4. **Class Result** — เปิดผลรวมของชั้นและอภิปรายเหตุผลที่แตกต่าง
5. **Case Card** — อ่านหลักฐานที่อนุมัติจากกรณี “โรงเรียนอรุณพัฒนา”
6. **Indicator Challenge** — เปลี่ยนปัญหา/ประเด็นเป็นตัวชี้วัดที่วัดได้
7. **Evidence vs Assumption** — แยกสิ่งที่มีหลักฐานออกจากสิ่งที่กำลังคาดเดา
8. **Decision Point** — เลือกตัวชี้วัดที่เหมาะสมและให้เหตุผล
9. **WS1 Assessment Planning** — บันทึก Problem → Indicator → Evidence Need
10. **Exit Ticket** — ระบุหนึ่งสิ่งที่ยัง “ตัดสินไม่ได้” และหลักฐานที่ต้องการเพิ่ม

### Student product
**WS1 — Assessment Planning**

### Evidence rule
ใช้เฉพาะข้อมูลกรณีศึกษาที่ได้รับอนุมัติ ห้ามสร้างตัวเลขหรือข้อเท็จจริงของโรงเรียนเพิ่มเติมเอง
